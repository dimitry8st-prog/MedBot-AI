# Соглашения по оформлению документов

> Правила создания и редактирования документов в MedBot AI Knowledge Base

---

## 📝 Нейминг файлов

### Протоколы

**Формат:** `{Полное название заболевания}.md`

✅ **Правильно:**
- `Артериальная гипертензия.md`
- `Ишемический инсульт.md`
- `Сахарный диабет 2 типа.md`

❌ **Неправильно:**
- `АГ.md` (использовать полное название, сокращения — в aliases)
- `гипертония.md` (с маленькой буквы)
- `Артериальная_гипертензия.md` (нижнее подчеркивание)

### Препараты

**Формат:** `{МНН с заглавной буквы}.md`

✅ **Правильно:**
- `Метформин.md`
- `Амлодипин.md`

❌ **Неправильно:**
- `метформин.md`
- `Сиофор.md` (торговое название → в aliases)

### Симптомы

**Формат:** `{Название симптома}.md`

✅ **Правильно:**
- `Головная боль.md`
- `Одышка.md`

## 📋 Frontmatter

### Обязательные поля для протоколов

```yaml
---
title: "Полное название"                 # ОБЯЗАТЕЛЬНО
specialty: "специальность"               # ОБЯЗАТЕЛЬНО
source: "Минздрав РФ"                    # ОБЯЗАТЕЛЬНО
source_type: clinical_recommendations    # ОБЯЗАТЕЛЬНО
publication_year: 2024                   # ОБЯЗАТЕЛЬНО
evidence_level: "A"                      # ОБЯЗАТЕЛЬНО
status: active                           # ОБЯЗАТЕЛЬНО
created: 2026-07-28                      # ОБЯЗАТЕЛЬНО
updated: 2026-07-28                      # ОБЯЗАТЕЛЬНО
tags: [протокол, специальность]         # ОБЯЗАТЕЛЬНО
aliases: []                              # опционально
icd10: "I10"                            # желательно
---
```

### Допустимые значения

**`specialty`:**
- кардиология
- неврология
- хирургия
- терапия
- эндокринология
- пульмонология
- гастроэнтерология
- нефрология
- ревматология
- онкология
- ... (по специальностям)

**`source_type`:**
- `clinical_recommendations` — клинические рекомендации
- `protocols` — протоколы лечения
- `drug_reference` — справочник лекарств
- `textbooks` — учебники
- `articles` — научные статьи

**`evidence_level`:**
- `A` — систематические обзоры, мета-анализы, РКИ
- `B` — контролируемые исследования
- `C` — наблюдательные исследования
- `D` — описания случаев, мнения экспертов
- `E` — консенсус экспертов

**`status`:**
- `active` — актуальный документ (используется в RAG)
- `archived` — устаревший (не индексируется)
- `draft` — черновик (не индексируется)

**`tags`:**
- Всегда начинать с `протокол` или `препарат` или `симптом`
- Добавлять специальность
- Добавлять ключевые слова (3-7 тегов)
- Использовать дефисы вместо пробелов: `#сахарный-диабет`

## 🔗 Wikilinks

### Правила создания

**Когда создавать wikilink:**
- ✅ Первое упоминание заболевания, препарата, симптома
- ✅ Связанные состояния в разделе "Осложнения"
- ✅ Препараты в разделе "Лечение"
- ✅ Дифференциальная диагностика

**Когда НЕ создавать wikilink:**
- ❌ Общие термины (артериальное давление, глюкоза крови)
- ❌ Повторное упоминание в том же абзаце
- ❌ Несущественные упоминания

### Форматы wikilinks

```markdown
[[Документ]]                           # простая ссылка
[[Документ|Альтернативный текст]]      # с другим текстом отображения
[[Документ#Раздел]]                    # ссылка на раздел
[[Документ#Раздел|Текст]]              # ссылка на раздел с текстом
```

### Примеры

```markdown
Основные факторы риска включают [[Артериальная гипертензия]] и [[Сахарный диабет 2 типа]].

Препараты первой линии: [[Метформин]] и [[Ингибиторы ДПП-4]].

При развитии осложнений возможен [[Инфаркт миокарда]] или [[Инсульт]].

Подробнее о дозировке см. [[Метформин#Дозировка]].
```

### Целевое количество wikilinks

| Тип документа | Минимум wikilinks |
|---------------|-------------------|
| Протокол | 10-20 |
| Препарат | 3-5 |
| Симптом | 5-10 |

## 📐 Структура документа

### Протокол (клинические рекомендации)

**Обязательные разделы:**

1. **Метаданные (callout)**
   ```markdown
   > [!info] Метаданные
   > **Источник:** ...
   > **Год:** ...
   > **Уровень доказательности:** ...
   ```

2. **Определение** — краткое определение заболевания (1-2 абзаца)

3. **Эпидемиология** — распространенность, факторы риска

4. **Классификация** — если применимо (степени, стадии, типы)

5. **Клинические проявления** — симптомы, осложнения

6. **Диагностика** — критерии, методы обследования

7. **Лечение** — цели, немедикаментозное, медикаментозное

8. **Профилактика** — первичная, вторичная

9. **Прогноз**

10. **Связанные темы** — wikilinks на связанные документы

11. **Источники**

12. **История изменений**

### Препарат

**Обязательные разделы:**

1. Общая информация (МНН, торговые названия, класс)
2. Механизм действия
3. Показания
4. Дозировка
5. Противопоказания
6. Побочные эффекты
7. Лекарственные взаимодействия
8. Мониторинг
9. Альтернативы
10. Связанные протоколы

### Симптом

**Обязательные разделы:**

1. Описание
2. Встречается при (заболевания)
3. Дифференциальная диагностика
4. Тактика при выявлении
5. "Красные флаги"
6. Связанные симптомы

## 🎨 Форматирование

### Заголовки

```markdown
# Заголовок уровня 1 — только название документа
## Заголовок уровня 2 — основные разделы
### Заголовок уровня 3 — подразделы
#### Заголовок уровня 4 — редко используется
```

### Callouts (блоки внимания)

```markdown
> [!info] Информация
> Полезная справка

> [!warning] Предупреждение
> Важно обратить внимание

> [!danger] Опасность
> Критически важная информация (противопоказания, побочки)

> [!tip] Совет
> Практические рекомендации

> [!note] Примечание
> Дополнительная информация
```

### Списки

**Маркированные:**
```markdown
- Пункт 1
- Пункт 2
  - Подпункт 2.1
  - Подпункт 2.2
```

**Нумерованные:**
```markdown
1. Первый шаг
2. Второй шаг
3. Третий шаг
```

**Чеклисты:**
```markdown
- [ ] Не выполнено
- [x] Выполнено
```

### Таблицы

```markdown
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
|-------------|-------------|-------------|
| Ячейка 1    | Ячейка 2    | Ячейка 3    |
| Ячейка 4    | Ячейка 5    | Ячейка 6    |
```

**Выравнивание:**
```markdown
| Влево | По центру | Вправо |
|:------|:---------:|-------:|
| Текст | Текст     | Текст  |
```

### Эмодзи (использовать умеренно)

✅ **Допустимо:**
- ✅ ❌ ⚠️ — для обозначения статуса
- 📊 📈 📉 — для статистики
- 🔗 📚 📝 — для навигации

❌ **Избегать:**
- Эмодзи в середине предложений
- Слишком много эмодзи (>5 на документ)

## 📊 Таблицы (специальные случаи)

### Дозировки препаратов

```markdown
| Показание | Начальная доза | Целевая доза | Максимальная доза |
|-----------|----------------|--------------|-------------------|
| СД2       | 500 мг/сут     | 2000 мг/сут  | 3000 мг/сут       |
```

### Классификация

```markdown
| Степень | Критерий | Описание |
|---------|----------|----------|
| I       | 140-159  | Легкая   |
| II      | 160-179  | Средняя  |
| III     | ≥180     | Тяжелая  |
```

### Дифференциальная диагностика

```markdown
| Признак | Заболевание 1 | Заболевание 2 | Заболевание 3 |
|---------|---------------|---------------|---------------|
| Температура | Высокая | Норма | Субфебрильная |
| Боль | Острая | Хроническая | Отсутствует |
```

## 🔢 Единицы измерения

### Стандарты

- **АД:** мм рт.ст. (не mmHg)
- **Масса тела:** кг
- **Рост:** см или м
- **Глюкоза:** ммоль/л (указывать единицы!)
- **Дозировки:** мг, г, мл (с пробелом: `500 мг`, не `500мг`)
- **Частота:** раз/сутки, мг/кг/сутки

### Диапазоны

```markdown
5-10 мг/сутки     # через дефис без пробелов
<140 мм рт.ст.    # знак меньше без пробела перед числом
≥7.0 ммоль/л      # символ ≥ (не >=)
```

## 📅 Даты

**Формат:** YYYY-MM-DD (ISO 8601)

```yaml

```

**В тексте:**
- Год: 2024
- Дата полностью: 28 июля 2026 года

## 🔍 Поиск и индексация

### Ключевые слова для поиска

При создании документа думать о том, **как врачи будут искать** эту информацию:

**Хорошо:**
- Полное название + сокращение в aliases
- Синонимы (гипертония = артериальная гипертензия = АГ)
- Торговые названия препаратов в aliases
- Распространенные опечатки (опционально)

**Плохо:**
- Слишком короткие aliases (1-2 буквы)
- Нерелевантные синонимы

### Оптимизация для RAG

**Важно для качественного поиска:**

1. **Frontmatter полностью заполнен** — используется для фильтрации
2. **Определение в начале** — часто попадает в первый чанк
3. **Структурированность** — заголовки помогают навигации
4. **Wikilinks** — создают граф знаний
5. **Ключевые термины выделены** — жирным или в списках

## ✅ Чеклист перед публикацией

Перед добавлением нового документа проверить:

- [ ] Frontmatter заполнен полностью (все обязательные поля)
- [ ] Определение заболевания в начале документа
- [ ] Все разделы из template присутствуют
- [ ] Создано минимум 5-10 wikilinks
- [ ] Проверена орфография (F7 в Obsidian)
- [ ] Добавлены aliases (сокращения, синонимы)
- [ ] Указан год публикации источника
- [ ] Указан уровень доказательности
- [ ] Добавлена ссылка на источник
- [ ] Обновлен раздел "История изменений"

## 🚫 Чего избегать

❌ **Не делать:**

- Копировать текст без переработки (риск нарушения авторских прав)
- Добавлять мнения без источников ("по моему опыту...")
- Использовать ненормативную лексику
- Добавлять персональные данные пациентов
- Создавать дубликаты документов
- Оставлять placeholder'ы из template ({{название}}, {{год}})
- Использовать абсолютные пути в ссылках
- Добавлять рекламу препаратов/производителей
