### 2. Тестирование RAG поиска

**Типовые тестовые запросы:**

| Запрос | Ожидаемый документ | Проверяемая функция |
|--------|-------------------|---------------------|
| "Целевые уровни АД при гипертонии" | TEST_cardiology_hypertension_2024.txt | Semantic search |
| "Тромболизис при инсульте в первые часы" | TEST_neurology_stroke_2024.txt | Temporal relevance |
| "Препараты первой линии при диабете 2 типа" | TEST_therapy_diabetes_2024.txt | Drug information |
| "Показания к операции при аппендиците" | TEST_surgery_appendicitis_2023.txt | Procedure guidelines |
| "Лечение COVID-19 дексаметазоном" | TEST_therapy_covid19_2024.txt | Current protocols |

**Тестовый скрипт:**
```python
# backend/tests/test_rag_search.py
import pytest
from app.core.rag_engine import RAGEngine

@pytest.mark.asyncio
async def test_search_hypertension():
    rag = RAGEngine()
    results = await rag.search("целевые уровни АД при гипертонии", top_k=3)
    
    assert len(results) > 0
    assert results[0].metadata["specialty"] == "кардиология"
    assert "140/90" in results[0].text or "130/80" in results[0].text
```

# Тестовые документы 2023-2024 (актуальны)

    score=0.9,
    source="Минздрав РФ",

    current_year=2026

    score=0.9,
    source="Минздрав РФ",
    publication_year=2020,
    current_year=2026
)

# 2024 должен иметь выше score (recency_penalty = 1.0)
# 2020 должен иметь ниже (recency_penalty = 0.5)
