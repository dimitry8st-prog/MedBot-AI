### Если документ не найден на основном источнике

   ```
   "название документа" site:cr.minzdrav.gov.ru filetype:pdf
   ```

2. **Альтернативные источники:**
   - Сайты региональных минздравов
   - Сайты медицинских университетов
   - Профессиональные общества

3. **Если документа нет в открытом доступе:**
   - Замените на аналогичный из той же специальности
   - Обновите `documents_metadata.csv`

### Проверка качества скачанного PDF

После скачивания проверьте:

```python
# Откройте Python
import PyPDF2

pdf_path = "data/raw/cardiology_ocs_st_2023.pdf"
with open(pdf_path, 'rb') as f:
    pdf = PyPDF2.PdfReader(f)
    print(f"Страниц: {len(pdf.pages)}")
    print(f"Первая страница: {pdf.pages[0].extract_text()[:200]}")
```

**Хороший PDF:**
- Текст извлекается корректно (не скан с картинками)
- Больше 10 страниц
- Содержит структурированный текст

**Плохой PDF (скан):**
- Текст не извлекается или gibberish
- Только изображения
- Потребуется OCR (медленно и неточно)

### Именование файлов

**Строго следуйте шаблону:**
```
{специальность}_{краткое_название}_{год}.pdf
```

**Примеры:**
- ✅ `cardiology_ocs_st_2023.pdf`
- ✅ `neurology_stroke_2024.pdf`
- ❌ `ОКС 2023.pdf` (неправильно)
- ❌ `document1.pdf` (неправильно)

## Автоматизация (опционально)

### Скрипт для batch скачивания (если есть прямые ссылки)

```python
# backend/scripts/batch_download.py
import requests
from pathlib import Path

# Список прямых ссылок (заполнить вручную)
DIRECT_LINKS = {
    "cardiology_ocs_st_2023.pdf": "https://example.com/ocs_2023.pdf",
    # ... остальные
}

def download_documents():
    for filename, url in DIRECT_LINKS.items():
        filepath = Path("data/raw") / filename
        if filepath.exists():
            print(f"Пропуск: {filename} (уже существует)")
            continue

        print(f"Скачивание: {filename}...")
        response = requests.get(url)
        if response.status_code == 200:
            with open(filepath, 'wb') as f:
                f.write(response.content)
            print(f"✓ Скачан: {filename}")
        else:
            print(f"✗ Ошибка: {filename} (код {response.status_code})")

if __name__ == "__main__":
    download_documents()
```

**Использование:**
```bash
# Заполнить DIRECT_LINKS в скрипте
python backend/scripts/batch_download.py
```

## Troubleshooting (решение проблем)

### Проблема 1: Доступ к cr.minzdrav.gov.ru ограничен

**Решение:**
- Используйте VPN (если блокировка)
- Попробуйте альтернативные источники (MedElement, профессиональные общества)
- Скачайте документы с сайтов региональных минздравов

### Проблема 2: Требуется регистрация

**Решение:**
- Зарегистрируйтесь на MedElement (бесплатно для врачей)
- Укажите специальность: "врач-терапевт" или аналог
- Используйте email: dimitry8st@gmail.com

### Проблема 3: PDF — скан (нет текстового слоя)

**Решение:**
- Попробуйте найти текстовую версию
- Используйте OCR (долго, неточно):
  ```bash
  tesseract input.pdf output pdf
  ```
- Замените на аналогичный документ с текстовым слоем

### Проблема 4: Документ устарел (год < 2023)

**Решение:**
- Найдите актуализированную версию на cr.minzdrav.gov.ru
- Если новой версии нет — используйте последнюю доступную
- Обновите год в `documents_metadata.csv`
