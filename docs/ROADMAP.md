## Этап 2: RAG Engine (ядро системы)
**Длительность:** 2 недели  
**Зависимости:** Этап 1

### Неделя 2.1: Ingestion & Indexing

#### 2.1.1. Document Ingestion Pipeline
- [ ] Написать парсер PDF (PyPDF2 + pdfplumber)

- [ ] Написать парсер HTML (BeautifulSoup)
- [ ] Написать парсер DOCX (python-docx)

- [ ] Реализовать semantic chunking

- [ ] Добавить metadata в каждый чанк (document_id, chunk_index, title)
- [ ] Тесты на разных типах документов

- [ ] Интегрировать sentence-transformers
  - Модель: intfloat/multilingual-e5-large
  - Batch processing (32 текста)
- [ ] Написать EmbeddingService класс
- [ ] Кэширование эмбеддингов (опционально, если медленно)

#### 2.1.4. ChromaDB Indexing
- [ ] Создать коллекцию `medical_documents`
- [ ] Написать функцию индексации документа
  - Чтение файла → парсинг → chunking → embeddings → сохранение в ChromaDB
- [ ] Скрипт массовой индексации (все 50 документов)
- [ ] Проверка: `collection.count()` должен вернуть ~500+ чанков

- [ ] Написать RAGEngine класс
- [ ] Метод `search(query: str, top_k: int)`:

#### 2.2.2. Reranking (опционально для MVP)
- [ ] Интегрировать cross-encoder модель
- [ ] Переранжирование топ-10 → топ-3
- [ ] Сравнение качества с/без reranking

#### 2.2.3. Интеграция с PostgreSQL
- [ ] SQLAlchemy модель `Document`
- [ ] Сохранение метаданных документов при индексации
