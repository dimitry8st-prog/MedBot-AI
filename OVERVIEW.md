## Что это?

**MedBot AI** — AI-платформа для медицинских специалистов с RAG-поиском по клиническим протоколам, анализом симптомов и поддержкой принятия решений на основе доказательной медицины.

**Ключевая идея:** Не заменить врача, а усилить его когнитивные возможности через быстрый доступ к структурированным знаниям и AI-анализ.

---

## Зачем этот проект?

### Проблемы врачей сегодня:
1. **Информационная перегрузка** — не успевают отслеживать обновления протоколов
2. **Низкая доступность экспертизы** — дефицит узких специалистов в регионах
3. **Сложность оценки источников** — много противоречивой информации

### Решение MedBot AI:
- Семантический поиск по медицинской базе знаний (RAG)
- AI-анализ симптомов с обоснованием и уровнем доказательности
- Доступ 24/7 через Web и Telegram

## Функциональность

### 1. RAG-поиск
Семантический поиск по клиническим рекомендациям и протоколам с указанием уровня доказательности (A/B/C/D/E).

**Пример запроса:**  
"Протокол лечения острого коронарного синдрома"

**Ответ:**  
Структурированный ответ с источниками, уровнем доказательности, ссылками на документы.

---

### 2. Анализ симптомов
Дифференциальная диагностика на основе описанных симптомов.

**Входные данные:**
- Основные жалобы
- Длительность
- Сопутствующие симптомы
- Факторы риска

**Результат:**
- 3–5 возможных диагнозов
- Вероятность (%)
- Обоснование
- Рекомендации по обследованию
- **Дисклеймер:** "Требуется консультация врача"

---

### 3. База протоколов
Поиск и просмотр клинических протоколов с фильтрами:
- Специальность
- Год публикации
- Уровень доказательности
- Источник

---

### 4. Аналитика
- Личная статистика (для врачей)
- Системная аналитика (для администраторов)
- Популярные запросы, оценки пользователей

---

### 5. Мультимодальность (опционально)
- OCR: распознавание текста на изображениях анализов
- Анализ медицинских изображений через multimodal LLM

## Как начать?

### Быстрый старт (локально)

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/dimitry8st-prog/medbot-ai.git
   cd medbot-ai
   ```

2. **Настроить переменные окружения**
   ```bash
   cp .env.example .env
   # Отредактировать .env (добавить API ключи)
   ```

3. **Запустить через Docker Compose**
   ```bash
   docker-compose up -d
   ```

4. **Применить миграции БД**
   ```bash
   docker-compose exec api alembic upgrade head
   ```

5. **Загрузить документы**
   ```bash
   docker-compose exec api python scripts/index_documents.py
   ```

6. **Открыть в браузере**
   - Web UI: http://localhost:3000
   - API Docs: http://localhost:8000/docs

**Детальные инструкции:** См. README.md
